# 語調守門員 Tone Guard

## 這是什麼

一套在 AI 寫中文的時候自動攔截的檢查程式。它掛在 Claude Code 的掛勾上，
AI 每一次要改檔案、發留言、提交版本、把事情交辦出去、或是回話，
都要先過一次這裡的檢查。

它不是第 201 條規則。規則是文字，讀到不等於照做；這裡的東西是程式，不過就是不過。

## 它能幫你做到什麼

先講量出來的數字，因為它推翻了原本的直覺。

近一個月 Vin 發出 964 則訊息，其中 39 則在抱怨產出品質：

| 抱怨的種類 | 則數 | 佔比 |
|---|---|---|
| 聽不懂、看不懂 | 26 | 67% |
| 該跑的檢查沒跑 | 5 | 13% |
| 內容零碎、太長 | 3 | 8% |
| 文案寫得爛 | 2 | 5% |
| 不像台灣人寫的 | 2 | 5% |
| 用了自己發明的詞 | 1 | 3% |

**三分之二的抱怨是「聽不懂」，用詞問題只佔 3%。**
再往下查那 26 則，發現問題幾乎都不在文筆，而是**他問的那件事沒有被回答**：
他問一句短的是非題，回覆卻是一份工作過程的交代。

所以這套程式的目標不是把句子潤順，是讓回覆先回答問題。

## 你現在要做什麼

```bash
bash install.sh
```

它會把這個 repo 的掛勾連進 `~/.claude/hooks`，再把規則與語料資料夾連進 `~/.claude`。
安裝完之後要自己在 `~/.claude/settings.json` 把五個掛勾掛上去，`install.sh` 會印出要貼的內容。

---

## 兩層檢查，各擋不同的東西

| 層 | 程式 | 擋什麼 | 目前的涵蓋率 |
|---|---|---|---|
| 第一層 掃詞 | `hooks/coined_word_guard.py` | 白紙黑字的用詞：自創量詞、口語動詞、比喻、把機器狀態講成人的動作 | 抓得到 Vin 實際退稿句子的 25% |
| 第二層 讀意思 | `hooks/copy_judge.py` | 他問的那件事有沒有被回答 | 還在調，目前只提醒不擋 |

第一層是正則加詞表，對錯沒有爭議，所以它可以直接擋。
第二層要另一個模型讀「他問的那一句」加上「AI 的回覆」，再給 0 到 10 分。
**它自己也會判錯，所以它要先考過試才准擋人**，見下面「怎麼考判官」。

另外三支各管一件事：

| 程式 | 做什麼 |
|---|---|
| `hooks/copy_gate_on_edit.py` | 這次編輯有沒有動到引號裡的中文。有的話，這一輪沒跑過文案 skill 就擋住 |
| `hooks/copy-voice-inject.py` | 每一輪把 Vin 自己寫過的句子送進 context |
| `hooks/complaint_learn.py` | 他一說「聽不懂」，就分析上一輪的問答，分四種原因寫進紀錄 |

## 語料在哪，為什麼不在這個 repo 裡

`copy-samples/` 底下有兩份語料，合計約 42 萬字：Vin 歷來打的中文訊息，
以及他自己寫的正式文件（研究報告、規格、簡報）約 32 萬字。
**兩份都被 `.gitignore` 擋在版控外面**，因為那是他本人的文件與私人訊息。
要重建就跑 `copy-samples/build_vin_corpus.py` 與 `extract_docs.py`。

正式文件那一份非補不可：日常對話只教得會口語，教不會正式文體。
Vin 自己講過「你自己寫過的東西 —— 規格、信、簡報、Google Docs。一份抵一百則對話」。

### 語料有三種污染，不擋就會讓 AI 自己的爛句子變成「他寫過的詞」

| 污染來源 | 長什麼樣 |
|---|---|
| 他退稿時把 AI 的爛句子一起打出來，跟他的修正並排 | `AI 的爛句子 --> 他的指正` |
| 他把 AI 的整份草稿貼回去要它改 | 那整段其實是 AI 寫的 |
| 檢查程式自己印出來的回報被當成他的訊息存下來 | 機器輸出混進語料 |

清理之前，40 個他親口退掉的詞裡有 20 個被誤判成「他自己也用過」。清乾淨之後剩 14 個。

## 怎麼考判官

沒有考題就等於再加一個會自我感覺良好的角色。

考題兩組，**兩組都是 AI 寫的稿，差別只在他當下有沒有抱怨**：
負樣本是他下一句就說「聽不懂」的那一則，對照組是他沒有抱怨的那一則。
第一版拿他自己打的訊息當對照組，結果判官學會的是分辨誰寫的，不是分辨好不好。

門檻不由判官自己決定，由考題決定：掃過 1 到 10 分，取抓到率減誤判率最高的那一個。
成績寫進 `copy-samples/judge-score.json`，`pass` 這個欄位決定它准不准擋人。

```bash
python3 copy-samples/build_gold.py     # 產生考題
python3 copy-samples/judge_exam.py --n 12
```

## 目前卡在哪

| 困難點 | 現況 |
|---|---|
| 判官不準，而且每動一次就更差 | 實測 70%／10% → 100%／60% → 92%／92% → 82%／64% → 55%／27% |
| 考題樣本太小 | 一次考 11 對 11，一個樣本等於 9 個百分點，分不出退步與雜訊 |
| 對照組是雜的 | 他沒抱怨不等於寫得好，可能只是當下沒空講 |
| 文件那一側沒有「他問的那一句」 | 沒有問題可比的時候，判官會反過來給好文件低分 |
| 判官會把他的口語改成公文 | 早期版本把他親手寫的六個句子全部退掉 |

## 檔案清單

| 資料夾 | 放什麼 |
|---|---|
| `hooks/` | 五支掛勾，安裝之後連到 `~/.claude/hooks` |
| `copy-rules/` | 情境目錄（12 種情境各自要掌握什麼）、情境路由、制度文件 |
| `copy-samples/` | 詞表、寫法規則、判官的評分規範，以及重建語料與考判官的程式 |

`copy-rules/文案品管制度.md` 是整套制度的說明，裡面有四張流程圖。
