# 這個資料夾：查表用的資料，跟三支產生它的程式

樣本句子跟著 `vin-toneguard-draft` 這個 skill 走
（`~/.claude/skills/vin-toneguard-draft/references/vin-voice.md`），
因為 skill 會同步到每一台機器，每個專案讀到的是同一份。
這裡放的是**文筆守門員要查的表**，以及把表算出來的程式。

## 檔案

| 檔案 | 是什麼 | 誰產生的 |
|---|---|---|
| `vin-raw-messages.jsonl` | 他歷來打給我的中文原文，7,000 多則。是我寫的被他貼回來的那幾行，存進去時就標在 `echo_lines` 欄位 | `copy-voice-inject.py` 每一輪追加 |
| `sources/` | 他自己寫的文件（88 頁菲律賓研究等） | 手動放進來 |
| `vin-corpus.txt` | 上面兩份清乾淨之後的句子，41.9 萬字（正式語體 31.8 萬字另存 vin-corpus-formal.txt） | `build_vin_corpus.py` |
| `rejected.jsonl` | 他退我稿的紀錄：我寫了什麼、他說要改成什麼 | 同上 |
| `coined-terms.json` | 他親口退過的 40 個詞，加 40 個還沒確認的候選 | 手動 ＋ `mine_candidates.py` |
| `copy-patterns.json` | 那些詞歸納出來的 6 種寫法 | 手動 |

## 三支程式

**`build_vin_corpus.py`** 把語料重建一次。有四種不是他打的東西要擋，
不擋的話我自己的用字會變成「他寫過的詞」。前三種它自己認得出來，第四種存進去的當下就標好了，它只負責跳過：

| 混進來的東西 | 長什麼樣 | 不擋的下場 |
|---|---|---|
| 他退稿時順手打出來的爛句子 | `菲律賓旅客講最多的一塊 --> 這不是台灣人報告會用的語法` | 「一塊」「講最多」被算成他寫過 |
| 他把我的稿整段貼回來要我改 | 帶反引號的那幾行 | 「送得動」被算成他寫過 |
| 文筆守門員自己的回報、系統提示、指令輸出 | `Stop hook feedback: ⛔ …` | 我的用字整批變成他的用字 |
| 他把我寫的字照原樣貼回來 | 沒有引號、箭頭、反引號，跟他自己打的看不出差別 | 我寫給他貼去別的對話測試的 prompt 變成他寫過的詞（2026-10-04 查出三則） |

2026-09-15 查出前三種的時候，40 個他親口退過的詞裡有 20 個因此被誤放。清乾淨之後剩 14 個，
那 14 個是他真的在聊天時用過的。

第四種重建時認不出來，所以改在存進去的當下比：`copy-voice-inject.py` 回完話把這一輪我寫出去的中文
（回話、寫進檔案與留言的字，連這一輪派出去的 agent 寫的都算）記在 `~/.claude/state/copy-voice/replies.jsonl`，
只留兩天，超過 60 萬字就先丟最舊的；他開口時逐行比連續八個字，六成以上出現過的那幾行寫進 `echo_lines`，
`build_vin_corpus.py` 與 `mine_candidates.py` 跳過那幾行。
門檻拿 7,050 則舊訊息驗證過：他親手改寫我一段話之後剩五成四，整段照貼是十成；
不到十二個字的短行要每一段都對得上才標，同一批裡標到 41 行，看過都是我的句子。

**`mine_candidates.py`** 找第 41 個詞。清單是他一個一個退出來的，所以永遠落後一個；
回頭數過，那 40 個裡有 25 個在他開口退之前我就用過十次以上。這支數我自己講過的
449 萬字，扣掉他寫過的，剩下「我常用、他從來沒用過」的四十個寫進 `candidates`。
那是一份給他掃三十秒的短名單，不是判定 —— 文筆守門員對候選只在同一份稿裡重複三次以上才提醒。

**`measure.py`** 印兩條線：他抱怨的比例、文筆守門員退我的次數。兩條要一起看，
抱怨降而退回沒降，代表文筆守門員在做事、我沒學到。

## 文筆守門員（Tone Guard）掛在哪

`~/.claude/hooks/coined_word_guard.py`，五個出口各一次：
改檔案、跑 `gh` 留言與開單、`git commit`、交事情給別人做、以及回話。
回話那一關第二次進來只講擋下來的那幾個，不然要引用一個退過的詞的時候會被連擋到上限。
